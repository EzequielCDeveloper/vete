# OpenSpec — VetCare / ProyectVet

Este directorio contiene las especificaciones formales (OpenSpec) para
el proyecto VetCare, un sistema de gestión veterinaria.

## Especificaciones

| Archivo | Descripción |
|---------|-------------|
| `specs/owasp-mitigation.md` | Plan de mitigación OWASP Top 10 2021 |

## Convenciones

- Los specs se escriben en español (idioma del proyecto).
- Cada spec sigue el formato: contexto, requirements, escenarios, criterios de aceptación.
- Las tareas derivadas se expresan en `/tasks/` (cuando corresponda).
